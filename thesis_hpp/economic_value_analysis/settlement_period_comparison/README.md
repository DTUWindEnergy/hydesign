# Settlement-period indifference-price comparison

This folder does two things:

1. It calculates the PPA indifference-price curves for hourly, daily, weekly
   and monthly PPA deviation settlement using the completed optimization runs.
2. It can directly validate one selected curve point by solving the model with
   both the PPA capacity and indifference price fixed.

The ordinary optimization results are only read. All new files are written to:

```text
economic_value_analysis/results/settlement_period_comparison/
```

## Settings

Open `settings.py` to choose the deviation penalties and the optional
validation case. The default figures examine `c_ppa=120`, `c_ppa=160` and
`c_ppa=200`. The default validation checks the monthly, `c_ppa=200`,
reference-price 80 case.

## 1. Calculate and plot

Run this from the `thesis_hpp` project root:

```bash
python -u economic_value_analysis/settlement_period_comparison/calculate_and_plot.py
```

This does not solve the optimization model. It creates one CSV containing all
48 calculated points and one figure for each selected `c_ppa` value.

The calculation applied to every settlement period `p` and reference run `k`
is:

```text
lambda_ind = lambda_reference + (J_merchant - J_reference) / E_PPA
```

Each period uses the optimal PPA capacity and annual contracted energy from
that period's completed run. Every figure overlays the four settlement-period
curves. The x-axis is the period-specific optimal PPA capacity and the y-axis
is its indifference price. The first and last points are labelled with their
original input prices of 40 and 100 EUR/MWh. All four reference prices remain
available in the output CSV. The plotted lines cover only the capacity ranges
generated by the four completed reference-price runs; they are not
extrapolated toward zero capacity. Comparing the periods at a common
fixed-capacity grid would require additional optimization runs.

## 2. Optional direct validation

The merchant case already exists and does not need to be rerun. Submit the
selected validation from the project root with:

```bash
sbatch --export=ALL,filename='economic_value_analysis/settlement_period_comparison/run_validation.py' economic_value_analysis/job_settings.sh
```

The validation fixes the selected period's optimal PPA capacity and its
calculated indifference price. Its mean-CVaR objective should equal the saved
merchant objective up to solver tolerance. The saved hourly merchant objective
is valid for every settlement period because all PPA obligations and shortfall
penalties disappear when `S_PPA=0`.
